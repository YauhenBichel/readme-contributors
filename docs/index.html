GitHub Action

README contributors

Fill a README with a contributors wall from the GitHub API. Bots are omitted. The wall is an SVG, not a <table>, so GitHub does not draw a grid around it. Any public repository can pin the v1.3.0 release.

How to use it Layouts Themes Source

Live demo: the default facepile, drawn from the py-harness contributors API.

How to use it

  1. Add a pair of markers to README.md.
  2. Call the Action. Pin the release tag, or a commit SHA if the job can write.
  3. Commit the rewritten README and .github/contributors.svg.

Markers:

<!-- readme: contributors,bots/- -start -->
<!-- readme: contributors,bots/- -end -->

Minimal workflow:

name: Contributors
on:
  schedule: [{ cron: "17 4 * * 0" }]
  workflow_dispatch:
permissions:
  contents: write
jobs:
  readme:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: YauhenBichel/readme-contributors@v1.3.0
        with:
          token: ${{ secrets.GITHUB_TOKEN }}
      - run: |
          git config user.name github-actions[bot]
          git config user.email 41898282+github-actions[bot]@users.noreply.github.com
          git add README.md .github/contributors.svg
          git diff --cached --quiet && exit 0
          git commit -m "docs: refresh README contributors"
          git push

A protected default branch should open a pull request instead of pushing. A copy-paste job is in examples/contributors.yml.

Layouts

Set layout. The default stays the overlapping facepile.

facepile

Overlapping circles. First person sits on top.

- uses: YauhenBichel/readme-contributors@v1.3.0
  with:
    token: ${{ secrets.GITHUB_TOKEN }}
    layout: facepile

grid

Spaced circles. Wraps at columns.

- uses: YauhenBichel/readme-contributors@v1.3.0
  with:
    token: ${{ secrets.GITHUB_TOKEN }}
    layout: grid

tiles

Rounded squares instead of circles.

- uses: YauhenBichel/readme-contributors@v1.3.0
  with:
    token: ${{ secrets.GITHUB_TOKEN }}
    layout: tiles

list

Avatar, name, and login on each row.

- uses: YauhenBichel/readme-contributors@v1.3.0
  with:
    token: ${{ secrets.GITHUB_TOKEN }}
    layout: list

compact

A tighter grid when the list is long.

- uses: YauhenBichel/readme-contributors@v1.3.0
  with:

    layout: compact
